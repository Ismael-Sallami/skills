# Sallami skills

Open-source agent skills and Claude Code plugins.

```bash
claude plugin marketplace add Ismael-Sallami/skills
claude plugin install agent-desktop-linux-cursor@sallami-skills
```

Every plugin is also a standard skill (`SKILL.md`), usable from any agent:
`npx skills add Ismael-Sallami/<repo>`.

| Plugin | What it does | Pro |
|---|---|---|
| [agent-desktop-linux-cursor](https://github.com/Ismael-Sallami/agent-desktop-linux-cursor) | An isolated Linux desktop for AI agents | [adc Pro](https://www.agensi.io) |
